# Переключатель микрофонов

Один exe-файл на рабочем столе: **«Переключатель микрофонов.exe»**.
Ничего устанавливать не нужно — Python не требуется.

## Виртуальный микрофон для Discord

Программа создаёт «виртуальный микрофон»: звук с выбранного физического
микрофона автоматически течёт в устройство **Virtual Audio Cable (VAC)**.
В Discord (и любой другой программе) один раз выбираешь вход
**Line 1 (Virtual Audio Cable)** как микрофон — и дальше просто жмёшь
gорячую клавишу: в Discord сразу звучит новый микрофон, без перенастроек.

Схема:  `физический микрофон → (роутер в программе) → VAC (Line 1) → Discord`

Драйвер **VAC 4.65** уже установлен (папка `C:\vac465`, установка через
`setup64.exe`). После установки в окне программы появляется зелёная
строка «✅ Виртуальный микрофон: готов».

Пока виртуальный кабель не установлен, программа работает как раньше —
просто переключает системный микрофон «по умолчанию».

## Как пользоваться

1. Двойной клик по **Переключатель микрофонов.exe** на рабочем столе
2. Жми горячую клавишу (по умолчанию **F9**, у тебя стоит **Scroll Lock**) —
   микрофон переключается: и системный «по умолчанию», и в виртуальный
3. В окошке виден текущий микрофон (подсвечен зелёным)
4. **Двойной клик** по микрофону в списке — выбрать его сразу
5. Кнопка **«Скрыть»** — прячет окно
6. Кнопка **«Выйти»** — закрывает программу

Программа не запускается дважды: повторный запуск просто сообщит, что
она уже работает (иначе горячая клавиша срабатывала бы дважды).

## Исключение микрофонов

Если какие-то микрофоны не должны участвовать в переключении (например,
виртуальные «Steam Streaming Microphone» или «SteelSeries Sonar»):

1. **Правый клик** по микрофону в списке — он исключается и помечается **✖**
2. F9 теперь переключает только оставшиеся микрофоны
3. Ещё раз **правый клик** — вернуть микрофон в переключение

Список исключений сохраняется рядом с exe в файле `mic_switcher.json`
и не сбрасывается при перезапуске. Можно удалить этот файл, чтобы сбросить
настройки.

## Настройка клавиши

Прямо в окне программы: строка **«Горячая клавиша»** → кнопка **«Сменить…»** →
введи новую и подтверди. Клавиша меняется сразу, сохраняется в `mic_switcher.json`.

Форматы: `f10`, `f12`, `ctrl+m`, `alt+f1`, `shift+f5`, `scroll lock`, `caps lock`,
`num lock`, `pg up`, `pg dn`, `home`, `end`, `insert`, `delete`, `print screen` и т.п.
Пробелы допустимы (`scroll lock` = `scrolllock`).

## Уведомления

При каждом переключении в правом верхнем углу экрана на ~2 секунды
показывается, какой микрофон включился. То же при исключении/возврате
микрофона и смене горячей клавиши.

## Автозапуск (по желанию)

`Win+R` → `shell:startup` → Enter, создай там ярлык на exe.
